## Увод

**OniAnvil** (*назив потиче од **Oni**on-Skinning (лукова кора / провидни слојеви) + **Anvil** (наковањ за ковање спрајтова)*) је отворени, високоперформансни уређивач пиксел арта и пакет за анимацију, написан у програмском језику Rust. Покреће се изворно уз хардверски убрзано исцртавање на оперативним системима Windows, Linux и macOS, као и без икакве инсталације директно унутар модерних веб прегледача путем WebAssembly технологије.

Већина постојећих едитора спрајтова третира анимацију као скуп неповезаних датотека слика, што приморава програмере на заморне кораке извоза, исецања и поновног паковања. **OniAnvil из корена мења ову парадигму:** текстурни атлас листа спрајтова за игре (`atlas_rgba`) представља основни извор истине. Ћелије кадрова, траке слојева, анимационе ознаке и тачке судара непрекидно су недеструктивно усклађени са атласом.

### Зашто OniAnvil?
- 🚀 **Муњевите перформансе изворног Rust кода**: Тренутно покретање за мање од једне милисекунде, кристално чисто исцртавање погоњено модулима `wgpu` и `egui 0.31`, без икаквог сецкања при прегледу дугачких временских линија.
- 🎬 **Вишеканална временска линија слојева**: Нелинеарне траке слојева (`V1, V2, V3...`) са слагањем одозго надоле, спајањем надоле, повезаним кадровима и подесивим трајањем задржавања.
- 🧅 **Врхунски систем лукове коре (Onion Skinning)**: Приказ више суседних кадрова са независним нијансирањем унапред/уназад, прилагодљивим кривама провидности и преливањем кроз петљу.
- 🎨 **Тренутни скинови палета ликова**: Креирајте дневне/ноћне варијанте, тимске боје или елементарне скинове уз ремапирање боја атласа у реалном времену и увоз/извоз GPL/PAL/HEX формата.
- 📦 **Директан извоз за играчке погоне**: Извозите скалиране PNG слике са екструдованим ивичним пикселима ради елиминисања непожељних шавова приликом филтрирања текстура у 2D погонима (Godot, Bevy, Raylib, Defold), заједно са стандардним Sprite Sheet JSON метаподацима и анимираним GIF-овима.

## Свеобухватни преглед алатки

OniAnvil садржи 15 професионалних алатки за цртање, геометрију, избор и метаподатке. Иконице се приказују помоћу библиотеке отвореног кода **Font Awesome Free** *(иконице: CC BY 4.0, фонтови: SIL OFL 1.1)*.

| Алатка | Иконица | Пречица | Величина четкице | Pixel Perfect | Опис |
|:---|:---:|:---:|:---:|:---:|:---|
| **Оловка** | ✏️ | <kbd>B</kbd> | 1..32 px | Да | Основна алатка за цртање. У режиму 1px подржава опцију **Pixel-Perfect** (аутоматски уклања ружне степеничасте L-углове). Подржава корисничке четкице из избора (`Ctrl/Cmd+B`). |
| **Гумица** | 🧹 | <kbd>E</kbd> | 1..32 px | Не | Брише пикселе до потпуне провидности (`[0, 0, 0, 0]`). Ограничена је активном маском избора уколико постоји. |
| **Капаљка** | 💉 | <kbd>I</kbd> / <kbd>Alt</kbd> | 1 px | Не | Леви клик узима боју у основну (Foreground); десни клик у позадинску (Background). Може узимати боју са платна, слојева или референтне скице. |
| **Кантица** | 🪣 | <kbd>G</kbd> | Није доступно | Не | Брзо алгоритамско попуњавање редом (BFS) уз подесиви праг толеранције (`0..=255`). Подржава повезано и глобално попуњавање и ограничење избором. |
| **Градијент** | 🌈 | <kbd>G</kbd> *(промена)* | Није доступно | Не | Линеарни и радијални прелази између основне и позадинске боје. Подржава Bayer (2x2, 4x4, 8x8) и Blue Noise дидеринг уз регулацију јачине. |
| **Линија** | 📏 | <kbd>L</kbd> | 1..32 px | Да | Брезенхамов алгоритам за праве линије са прегледом повлачења уживо. Држите <kbd>Shift</kbd> за закључавање углова на кораке од 45°/90°. |
| **Крива** | 〰️ | <kbd>C</kbd> | 1..32 px | Да | Квадратна Безјеова крива у 3 клика. Клик 1 поставља почетак, Клик 2 крај, покрет миша савија закривљеност, Клик 3 потврђује криву. |
| **Правоугаоник** | ⬜ | <kbd>U</kbd> | 1..32 px | Не | Контурни или попуњени геометријски правоугаоници. Држите <kbd>Shift</kbd> за задржавање пропорција квадрата 1:1. |

| **Четкица за дидеринг** | 🏁 | <kbd>D</kbd> | 1..32 px | Не | Црта шаховске дидеринг шаре између основне и позадинске боје без додавања нових боја у палету. |

## Функционална документација

### 1. Двојна архитектура усмерена на атлас

У OniAnvil-у, главни текстурни атлас листа спрајтова (`atlas_rgba`) представља стварну текстуру онако како је учитава ваш играчки погон:
- **Режим кадра (Frame Mode)**: Фокусира се на један активни кадар анимације, пружајући платно за прецизан рад са пикселима. Свака измена одмах ажурира одговарајућу ћелију у текстури атласа.
- **Режим атласа (Atlas Mode)**: Приказује комплетну мрежу листа спрајтова, омогућавајући макро прилагођавања, проверу поравнања између кадрова и групно уређивање.
- **Пропратна датотека**: Пројекти чувају чисте `.png` слике праћене лаганом пропратном метаподацима датотеком `.onianvil.json` која садржи распоред кадрова, хијерархију слојева, ознаке, множиоце задржавања и скинове палета.

### 2. Вишеканална временска линија слојева

Доња временска линија је конципирана по узору на професионалне нелинеарне видео едиторе:
- **Траке слојева (`V1, V2, V3...`)**: Слојеви су визуелно сложени одозго надоле. Трака постављена више на временској линији (`V1`) исцртава се на врху платана.
- **Контроле слојева**:
  - Кликните на ознаке `V1` / `V2` за брзу промену активног слоја за цртање.
  - Укључите/искључите видљивост слоја (иконица ока) и закључавање уређивања (иконица катанца).
  - Прилагодите провидност појединачног слоја (`0%..=100%`).
  - Померите слој горе/доле у хијерархији, дуплирајте слој или га спојите надоле (Merge Down) у слој испод.
  - Безбедно брисање слоја уз дијалог потврде.
- **Исечци кадрова (Frame Clips)**:
  - Множилац задржавања (Hold): доделите прилагођено трајање кадру (нпр. `2×`, `3×` задржавање за паузе или снажне ударце).
  - Повезани кадрови (`🔗`): повежите кадрове који се понављају дуж анимације тако да измена једног аутоматски ажурира све повезане примерке.
  - Понављање ознака: организујте анимације у именоване ознаке (`idle`, `walk`, `attack`) и пуштајте одређене ознаке у петљи.
  - Контроле репродукције: Напред, Назад, Пинг-понг и Понављање (Loop) уз подесиву брзину кадрова (`1..=120` FPS).

### 3. Преглед анимације уживо у реалном времену

Десни панел за преглед репродукује ваше анимације у реалном времену, потпуно независно од зумирања или померања главног платна:
- **Филтрирање ознака**: Ограничите пуштање на одређене ознаке (`walk`, `jump`) или пустите цео низ анимације.
- **Контроле репродукције**: Пусти, Паузирај, Претходни кадар, Следећи кадар, Укључивање петље и прилагођене брзине пуштања (`0.25x..=4.0x`).
- **Режими приказа**: Пребацивање између тамне шаховнице, светле шаховнице, чисте беле, чисте црне или прилагођене боје позадине.

### 4. Напредни систем провидних слојева (Onion Skinning)

Обликујте флуидне анимације уз наменски систем лукове коре:
- **Прилагођено нијансирање**: Независне боје нијансирања за претходне кадрове (подразумевано: црвена) и следеће кадрове (подразумевано: плава).
- **Опадање провидности**: Подесива основна провидност и криве постепеног опадања провидности за сваки наредни корак.
- **Преливање преко петље**: Омогућава провидан приказ првог кадра кроз последњи приликом израде бешавних циклуса.
- **Брзи увид (Quick-Peek)**: Држите тастер <kbd>Размак</kbd> без превлачења за тренутни преглед суседних кадрова.

### 5. Паметни референтни слој и цртање по скицама

Убрзајте свој рад цртањем преко ручно нацртаних скица или референтних фотографија:
- **Формати**: Учитавање референтних слика у форматима PNG, JPEG и WebP.
- **Режими стапања**: Подлога (испод ваших пиксел слојева) или Прекривање (изнад ваших слојева).
- **Контроле трансформације**: Независно зумирање, померање положаја, ротација и клизач провидности.
- **Паметно узорковање боја**: Користите капаљку на слоју скице уз опционо аутоматско привлачење најближој боји у активној палети пројекта.
- **Претварање у пикселе (1-Click Bake)**: Једним кликом спојите скалирану референтну слику директно у пиксел арт активног кадра.

### 6. Прецизне алатке за избор и марширајући мрави

- **Анимирани марширајући мрави**: Активни избори приказују динамичну, двобојну испрекидану ивицу високе видљивости (попут програма Photoshop или Aseprite).
- **Пун ласо избор са спољашњим попуњавањем**: За разлику од једноставних алгоритама праћења зрака који стварају рупе код петљи које се преклапају, OniAnvil ласо прави затворену 8-повезану границу и попуњава спољашњи простор, чиме обезбеђује 100% пун избор без рупа.
- **Радње са избором**: Прошири, Скупи, Граница (са кружним, квадратним или ромбоидним обликом језгра), Помери, Обрни, Обриши, Слободно ротирај и Копирај/Исеци/Налепи путем системског бафера.
- **Копирање и лепљење између кадрова**: Изаберите област на једном кадру, притисните <kbd>Ctrl/Cmd+C</kbd>, пређите на други кадар и притисните <kbd>Ctrl/Cmd+V</kbd> — пиксели се лепе тачно на истим релативним координатама без обзира на распоред тастатуре.

### 7. Ефекти уживо, филтери и RotSprite

Сви сликовни ефекти садрже поље за потврду **Преглед уживо** које приказује измене на платну у реалном времену и омогућава одустајање без нарушавања историје опозива:
- **Замена боје (`Shift+R`)**:
  - Интерактивна капаљка: кликните иконицу капаљке и одаберите боје директно са платна или из панела палете.
  - Трака за брзи избор из палете: леви клик бира боју „Из“, десни клик бира боју „У“.
  - Клизач толеранције и групна замена на свим кадровима анимације одједном.
- **Прилагођавање боја (`Ctrl/Cmd+U`)**: Подешавање HSV нијансе (Hue), засићења (Saturation), вредности осветљености (Value) и контраста у реалном времену.
- **Генератор аутоматске контуре**: Стварање оштрих пиксел контура ликова (Споља, Изнутра, По средини) са квадратним или косим (ромб) угловима.
- **Матрични филтери 3×3**: Замућење (Blur), Изоштравање (Sharpen), Препознавање ивица (Edge Detect) и Рељеф (Emboss) уз очување алфа канала.
- **Слободно ротирање (`Ctrl/Cmd+Shift+R`)**: Ротирајте изабране области или целе кадрове под било којим углом помоћу класичног алгоритма **RotSprite** или Nearest Neighbor.
- **Ремапирање на палету**: Пребацује боје платна у активну палету користећи Bayer дидеринг (2x2, 4x4, 8x8) или Blue Noise алгоритам.

### 8. Управљање палетама, замена боја и скинови ликова

- **Уграђене палете**: Преко 20 аутентичних ретро палета укључујући Game Boy, PICO-8, Commodore 64, NES, Endesga 32, Solarized и Sweetie 16.
- **Увоз и извоз**: Подршка за GIMP палете (`.gpl`), PAL (`.pal`), Hex записе (`.hex`) и сликовне траке узорака (`.png`).
- **Замена палета (Скинови)**: Дефинишите више варијанти изгледа за једног лика (нпр. Подразумевано, Златни оклоп, Сенка, Ледено). Промена скина тренутно пресликава све боје кадрова у целом атласу.
- **Генератор прелаза боја**: Аутоматски гради глатке градијенте између две одабране нијансе уз подесив број међукорака.

### 9. Сечење листова, 9-делна мрежа интерфејса и извоз за играчке погоне

- **Сечење листова (Sheet Slicer)**: Аутоматско откривање граница аутокорелацијом сече сирове листове спрајтова у уједначене или прецизно обрезане кадрове анимације.
- **9-делно скалирање (9-Slice)**: Поставите подесиве маргине (горе, доле, лево, десно) за преглед прилагодљивих прозора корисничког интерфејса и дугмади без деформације углова.
- **Извоз PNG слика са екструдованим ивичним пикселима**: Проширује боје ивичних пиксела у провидна подручја чиме се елиминишу непожељни шавови и артефакти филтрирања текстура у графичким системима OpenGL, DirectX, Vulkan и 2D играчким погонима (као што је Godot).
- **Извоз анимираних GIF-ова**: Генерише оптимизоване анимиране GIF датотеке са прилагођеним бројем понављања, кашњењем кадрова и провидним позадинама.
- **Стандардни Sprite Sheet JSON**: Извози координате кадрова, ознаке, трајања и тачке ослонца усклађене са стандардном JSON шемом која се користи у модерним играчким погонима.

### 10. 35 ергономских тема и потпуна локализација

- **Колекција тема**: Studio Dark, Studio Light, Pitch Black, Cyberpunk Neon, Synthwave, Nord Frost, Dracula, Tokyo Night, Catppuccin Mocha, Gruvbox Dark, Monokai Pro, Solarized Dark, Solarized Light, фосфорни CRT екрани (Amber, Green, Cyan), ретро конзоле (Game Boy, Game Boy Light, Super Game Boy, NES/Famicom, SNES, Genesis/Mega Drive, PlayStation 1, PlayStation 2, Dreamcast) и ретро рачунари (C64, ZX Spectrum, Amiga Workbench, Atari ST, MSX, Apple II, DOS CGA, Mac Classic, Windows 98).
- **Потпуна вишејезичка подршка**: Тренутно пребацивање између 37 језика уз 100% покривеност свих порука и описа алатки.

- **Windows**: Преузмите `OniAnvil-windows-x86_64.zip`, распакујте архиву и покрените `OniAnvil.exe`.
- **Linux**: Преузмите `OniAnvil-linux-x86_64.tar.gz` (преносна верзија) или инсталирајте Debian/Ubuntu пакет:
  ```bash
  sudo dpkg -i onianvil_*_amd64.deb
  ```
- **macOS**: Преузмите `OniAnvil-macos-universal.zip`, распакујте и превуците `OniAnvil.app` у фасциклу Applications. Универзална бинарна датотека изворно ради и на Apple Silicon чиповима (M1/M2/M3/M4) и на Intel Mac рачунарима.
- **Веб (Web)**: Покрените директно у прегледачу без икакве инсталације: **[Покрени WebAssembly апликацију](https://rbm13s.github.io/OniAnvil/app/?lang=sr)**.
  > [!WARNING]
  > WebAssembly (веб) верзија има статус **Експериментално**. Због ограничења безбедносног окружења прегледача, разлика у WebGL/WebGPU графичким драјверима и ограничења системског бафера, могу се појавити мање графичке неправилности или слабије перформансе у поређењу са изворном верзијом за рачунаре. За професионалан рад снажно се препоручује изворна десктоп верзија.

### Изградња из изворног кода

#### Предуслови
- **Rust развојни алати**: Инсталирајте Rust (препоручује се верзија 1.80 или новија) путем [rustup.rs](https://rustup.rs/):
  ```bash
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  ```
- **Зависности за изградњу на Linux-у** (Debian/Ubuntu):
  ```bash
  sudo apt-get update
  sudo apt-get install -y build-essential pkg-config libxcb-render0-dev libxcb-shape0-dev \
    libxcb-xfixes0-dev libxkbcommon-dev libxkbcommon-x11-dev libssl-dev libgtk-3-dev libgl1-mesa-dev
  ```

#### 1. Компајлирање и покретање изворне верзије за рачунаре
```bash
# Клонирајте спремиште
git clone https://github.com/rbm13s/OniAnvil.git
cd OniAnvil

# Покрените тестове
cargo test

# Изградите и покрените оптимизовану дистрибутивну верзију
cargo run --release
```

#### 2. Компајлирање WebAssembly верзије (путем алата Trunk)
```bash
# Додајте циљну платформу wasm32 и алат Trunk
rustup target add wasm32-unknown-unknown
cargo install --locked trunk

# Покрените локални развојни сервер са аутоматским освежавањем
trunk serve

# Изградите оптимизоване датотеке за објаву у фасциклу docs/app/
./build_wasm.sh        # На Linux/macOS системима
./build_wasm.ps1       # На систему Windows PowerShell
```

## Формат датотека и пропратна архитектура

OniAnvil избегава затворене комерцијалне бинарне формате. Сваки пројекат се састоји од две чисте датотеке погодне за системе контроле верзија (Git):

```
my_character/
├── my_character.png            # Стандардни PNG текстурни атлас спрајтова (отвара се у било ком погону или прегледачу)
└── my_character.onianvil.json   # Пропратна JSON датотека са метаподацима пројекта
```

Пропратна датотека `.onianvil.json` чува:
- Конфигурацију мреже платна: димензије кадра, број колона, укупан број кадрова.
- Хијерархију слојева: називе трака, нивое провидности, заставице видљивости и стања закључавања.
- Ознаке анимација: назив, почетни/завршни кадар, смер пуштања (Напред, Назад, Пинг-понг), трајање кадрова.
- Дефиниције палета: активне узорке боја, именоване варијанте скинова, индекс тренутног скина.
- Стање референтне скице: путању слике, размеру, помак, угао ротације, провидност, режим слоја.
- Тачке ослонца и дејства: прилагођене тачке за механику, тачке за оружје и центре судара.
