## Уводзіны

**OniAnvil** (*назва паходзіць ад **Oni**on-Skinning (пакадравая калька) + **Anvil** (кавадла для кавання спрайтаў)*) — гэта адкрыты высакапрадукцыйны рэдактар піксельнай графікі і анімацыі, напісаны на мове Rust. Праграма працуе натыўна з апаратным паскарэннем графікі на Windows, Linux і macOS, а таксама непасрэдна ў браўзеры праз WebAssembly без неабходнасці ўсталёўкі.

У адрозненне ад класічных рэдактараў, дзе анімацыя ўспрымаецца як стос асобных файлаў выяў, што прымушаюць распрацоўшчыка займацца стомнай нарэзкай, экспартам і зваротнай зборкай у атласы, **OniAnvil першапачаткова ставіць у цэнтр атлас спрайтшыта (`atlas_rgba`)**. Ячэйкі кадраў, пласты, тэгі анімацыі і пункты прывязкі калізій бесперапынна сінхранізуюцца з агульнай тэкстурнай картай у неразбуральным рэжыме.

### Чаму OniAnvil?
- 🚀 **Маланкавая хуткасць Rust**: імгненны запуск за долі мілісекунды, выразны рэндэрынг на базе `wgpu` і `egui 0.31`, нулявыя затрымкі пры пракрутцы вялікіх таймлайнаў.
- 🎬 **Мантажны шматдарожкавы таймлайн**: дарожкі пластоў (`V1, V2, V3...`) з накладаннем зверху ўніз, зліццём пластоў, звязанымі кадрамі і гнуткімі множнікамі працягласці.
- 🧅 **Першакласны Onion Skinning**: шматкадравае калькіраванне з незалежным падфарбоўваннем папярэдніх і наступных кадраў (чырвоны/сіні), плаўным згасаннем празрыстасці і зацыкленнем.
- 🎨 **Імгненныя скіны персанажаў**: стварэнне варыяцый (дзень/ноч, камандныя колеры, стыхіі) за кошт апаратнага рэмапінгу палітраў непасрэдна ў атласе з імпартам і экспартам у GPL, PAL, HEX.
- 📦 **Прамая гатоўнасць да рухавікоў**: экспарт PNG з экструзіяй краявых пікселяў для ліквідацыі швоў фільтрацыі ў 2D-рухавіках (Godot, Bevy, Raylib, Defold), аптымізаваных GIF-анімацый і метададзеных Sprite Sheet JSON.

## Поўны даведнік інструментаў (Tools)

У OniAnvil даступна 15 прафесійных інструментаў для малявання, геаметрыі, вылучэння і метададзеных. Іконкі выкарыстоўваюць адкрыты шрыфт **Font Awesome Free** *(іконкі: CC BY 4.0, шрыфты: SIL OFL 1.1)*.

| Інструмент | Іконка | Гарачая клавіша | Памер пэндзля | Pixel Perfect | Апісанне |
|:---|:---:|:---:|:---:|:---:|:---|
| **Аловак** | ✏️ | <kbd>B</kbd> | 1..32 px | Так | Асноўны інструмент малявання. У рэжыме 1px падтрымлівае маляванне **Pixel-Perfect** (аўтаматычна ліквідуе кутнія L-схадзінкі). Падтрымлівае ўласныя штампы з вылучэння (`Ctrl/Cmd+B`). |
| **Гумка** | 🧹 | <kbd>E</kbd> | 1..32 px | Не | Ачышчае пікселі да поўнай празрыстасці (`[0, 0, 0, 0]`). Абмяжоўваецца маскай вылучэння, калі яна актыўная. |
| **Піпетка** | 💉 | <kbd>I</kbd> / <kbd>Alt</kbd> | 1 px | Не | ЛКМ выбірае колер у Асноўны (Foreground); ПКМ — у Фанавы (Background). Можа браць колеры з палатна, пластоў або пласта эскіза. |
| **Заліванне** | 🪣 | <kbd>G</kbd> | Не ўжыв. | Не | Хуткае алгарытмічнае заліванне на базе чаргі (BFS) з наладжвальным допускам колеру (Tolerance `0..=255`). Падтрымлівае сумежнае і глабальнае заліванне з улікам вылучэння. |
| **Градзіент** | 🌈 | <kbd>G</kbd> *(перакл.)* | Не ўжыв. | Не | Лінейныя і радыяльныя градзіенты паміж асноўным і фанавым колерамі. Падтрымлівае дызерынг Баера (2x2, 4x4, 8x8) і Blue Noise з кантролем сілы. |

## Функцыянальная дакументацыя

### 1. Атлас як адзіная крыніца ісціны

У OniAnvil галоўная тэкстура атласа (`atlas_rgba`) з'яўляецца першаснай крыніцай дадзеных і дакладна адпавядае тэкстуры спрайтшыта ў вашым гульнявым рухавіку:
- **Frame Mode (Рэжым кадра)**: Факусуецца на адным актыўным кадры анімацыі для спакойнай працы з пікселямі. Любыя змяненні імгненна абнаўляюць адпаведную ячэйку ў тэкстуры атласа.
- **Atlas Mode (Рэжым атласа)**: Адлюстроўвае ўсю сетку спрайтшыта, дазваляючы ацэньваць агульную кампазіцыю, правяраць выраўноўванне паміж кадрамі і ажыццяўляць пакетнае рэдагаванне.
- **Файл-кампаньён**: Праекты захоўваюцца ў выглядзе чыстага стандартнага відарыса `.png` разам з лёгкім метафайлам `.onianvil.json`, які апісвае сетку кадраў, іерархію пластоў, анімацыйныя тэгі, множнікі трымання і скіны палітры.

### 2. Шматдарожкавы таймлайн пластоў

Ніжні таймлайн распрацаваны па стандартах прафесійнага мантажнага софту:
- **Дарожкі пластоў (`V1, V2, V3...`)**: Пласты накладаюцца зверху ўніз. Дарожка, размешчаная вышэй на таймлайне (`V1`), малюецца па-над ніжнімі дарожкамі на палатне кадра.
- **Кіраванне дарожкамі**:
  - Клік па значках `V1` / `V2` для хуткага пераключэння актыўнага пласта малявання.
  - Пераключэнне бачнасці пласта (іконка Вока) і блакіроўкі ад змен (іконка Замка).
  - Налада празрыстасці асобнага пласта (`0%..=100%`).
  - Перамяшчэнне пласта ўверх/уніз у іерархіі, дубляванне і зліццё з пластом ніжэй (Merge Down).
  - Бяспечнае выдаленне пласта з дыялогам пацверджання.
- **Кадры і кліпы**:
  - Множнік утрымання (Hold): прызначэнне індывідуальнай працягласці кадраў (напрыклад, `2×`, `3×` для паўз або акцэнтаў перад ударам).
  - Звязаныя кадры (`🔗`): прывязка паўтаральных кадраў у межах анімацыі, дзе змяненне аднаго кадра аўтаматычна абнаўляе ўсе звязаныя асобнікі.
  - Анімацыйныя тэгі: упарадкаванне анімацый у тэгі (`idle`, `walk`, `attack`) і зацыкленае прайграванне абранага блока.
  - Кіраванне прайграваннем: Наперад, Назад, Пінг-понг і Зацыкленне з хуткасцю ад `1` да `120` FPS.

### 3. Жывы папярэдні прагляд анімацыі ў рэальным часе

Правая док-панэль Preview прайгравае вашу анімацыю ў рэальным часе незалежна ад зуму або становішча працоўнага палатна:
- **Фільтрацыя па тэгах**: Прайграванне толькі абранага тэга (`walk`, `jump`) або ўсяго ланцужка кадраў запар.
- **Кіраванне прайграваннем**: Кнопкі Play, Pause, крок назад, крок наперад, пераключальнік цыкла і множнікі хуткасці (`0.25x..=4.0x`).
- **Рэжымы адлюстравання**: Пераключэнне паміж цёмнай шахматкай, светлай шахматкай, чыстым белым, чыстым чорным або карыстальніцкім фонам.

### 4. Пашыраная сістэма калькі (Onion Skinning)

Стварайце плыўную анімацыю пры дапамозе спецыялізаванай сістэмы калькіравання:
- **Раздзельнае падфарбоўванне**: Незалежны выбар колеру падсветкі для папярэдніх кадраў (па змаўчанні чырвоны) і наступных кадраў (па змаўчанні сіні).
- **Крывая згасання празрыстасці**: Налада базавай празрыстасці і кроку паслаблення для кожнага наступнага аддаленага кадра.
- **Зацыклены пераход**: Падсветка першага кадра скрозь апошні пры стварэнні бясшвоўных цыклаў.
- **Хуткі прагляд (Quick-Peek)**: Утрыманне клавішы <kbd>Прабел</kbd> без перацягвання мышы імгненна падсвятляе суседнія кадры.

### 5. Пласт эскізаў і абводкі рэферэнсаў

Паскарайце працу шляхам абводкі накідаў, канцэпт-артаў або фота-рэферэнсаў:
- **Фарматы**: Загрузка відарысаў у фарматах PNG, JPEG і WebP.
- **Рэжымы змешвання**: Падкладка (Underlay, пад вашымі піксельнымі пластамі) або Накладанне (Overlay, па-над піксельнымі пластамі).
- **Трансфармацыя**: Незалежныя налады зуму, зрушэння пазіцыі, вугла павароту і паўзунок празрыстасці.
- **Разумная піпетка**: Узяцце колеру з эскіза з апацыйнай аўтаматычнай прывязкай да найбліжэйшага колеру актыўнай палітры праекта.
- **Запяканне ў адзін клік (1-Click Bake)**: Ператварэнне маштабаванага эскіза непасрэдна ў піксель-арт на актыўным кадры.

### 6. Высокадакладнае вылучэнне і «бегаючыя мурашы»

- **Аніміраваны контур «бегаючых мурашоў»**: Актыўнае вылучэнне падсвятляецца высокакантрастнай двухколернай пункцірнай лініяй, якая рухаецца.
- **Шчыльнае паліганальнае ласо (Solid Flood-Fill)**: У адрозненне ад простых алгарытмаў трасіроўкі прамянёў, якія ствараюць незапоўненыя дзіркі на скрыжаваных завесах, ласо ў OniAnvil будуе замкнёны 8-звязны контур і залівае знешнюю вобласць, гарантуючы 100% суцэльнае вылучэнне без дэфектаў.
- **Аперацыі з вылучэннем**: Пашырэнне, Сцісканне, Рамка (з круглай, квадратнай і ромбападобнай формамі ядра), Перасоўванне, Інвертаванне, Выдаленне, Свабодны паварот і Праца з сістэмным буферам абмену (Copy/Cut/Paste).
- **Скразное капіраванне паміж кадрамі**: Вылучыце патрэбную вобласць на адным кадры, націсніце <kbd>Ctrl/Cmd+C</kbd>, перайдзіце на любы іншы кадр і націсніце <kbd>Ctrl/Cmd+V</kbd> — фрагмент уставіцца па тых жа адносных каардынатах на любой раскладцы клавіятуры.

### 7. Жывыя эфекты, фільтры і RotSprite

Усе дыялогавыя вокны эфектаў маюць сцяжок **Жывы прагляд (Live Preview)**, які паказвае мадыфікацыі на палатне ў рэальным часе без засмечвання гісторыі адмен пры закрыцці:
- **Замена колеру (`Shift+R`)**:
  - Інтэрактыўная піпетка: клікніце па іконцы піпеткі і абярыце колер непасрэдна з пікселяў палатна або з панэлі палітры.
  - Хуткая паласа палітры: ЛКМ выбірае колер «З», ПКМ выбірае колер «На».
  - Паўзунок допуску (Tolerance) і пакетная замена колеру адразу па ўсіх кадрах анімацыі.
- **Калярокарэкцыя (`Ctrl/Cmd+U`)**: Зрух адцення HSV (Hue), насычанасці (Saturation), яркасці (Value) і кантрасту ў рэальным часе.
- **Аўтагенератар контуру**: Стварэнне выразнага піксельнага абвядзення персанажа (Звонку, Унутры, Па цэнтры) з прамымі (Square) або зрэзанымі (Diamond) вугламі.
- **Матрычныя згорткавыя фільтры 3×3**: Размыццё, Павышэнне рэзкасці, Выяўленне краёў і Цясненне з захаваннем альфа-канала.
- **Свабодны паварот (`Ctrl/Cmd+Shift+R`)**: Паварот вылучанай вобласці або ўсяго кадра на адвольны вугал алгарытмамі **RotSprite** або **Найбліжэйшы сусед (Nearest Neighbor)**.
- **Перапрывязка да палітры**: Квантаванне колераў палатна да актыўнай палітры з дызерынгам Баера (2x2, 4x4, 8x8) або Blue Noise.

### 8. Кіраванне палітрамі, своп і скіны персанажаў

- **Убудаваныя палітры**: Больш за 20 аўтэнтычных рэтра-палітраў (Game Boy, PICO-8, Commodore 64, NES, Endesga 32, Solarized, Sweetie 16 і інш.).
- **Імпарт і экспарт**: Падтрымка фарматаў GIMP Palette (`.gpl`), PAL (`.pal`), Hex (`.hex`) і графічных узораў (`.png`).
- **Своп палітраў (Скіны)**: Стварэнне некалькіх каляровых варыянтаў для аднаго персанажа (напрыклад, Базавы, Залатыя даспехі, Цень, Ледзяны). Пераключэнне скінаў імгненна перапрывязвае колеры па ўсім атласе.
- **Генератар рампаў колераў**: Аўтаматычная плаўная інтэрпаляцыя градыентных пераходаў паміж двума абранымі адценнямі з наладжвальнай колькасцю прамежкавых крокаў.

### 9. Нарэзчык спрайтшытаў, 9-Grid UI і экспарт для гульнявых рухавікоў

- **Нарэзчык спрайтшытаў (Sheet Slicer)**: Алгарытм аўтакарэляцыі меж аўтаматычна наразае гатовы ліст спрайтаў на раўнамерныя або шчыльна падагнаныя анімацыйныя кадры.
- **Маштабаванне 9-Grid (9-Slice)**: Налада маштабуемых палёў (верх, ніз, злева, справа) для папярэдняга прагляду інтэрфейсных вокнаў і кнопак без дэфармацыі вуглоў.
- **Экспарт PNG з экструзіяй краявых пікселяў**: Дубляванне колераў межавых пікселяў у празрыстыя палі поўнасцю прадухіляе з'яўленне швоў і артэфактаў білінейнай фільтрацыі тэкстур у OpenGL, DirectX, Vulkan і 2D-рухавіках (напрыклад, Godot).
- **Экспарт аніміраваных GIF**: Генерацыя аптымізаваных аніміраваных GIF з наладай колькасці цыклаў, затрымак паміж кадрамі і падтрымкай празрыстасці.
- **Стандартны Sprite Sheet JSON**: Экспарт зрэзаў кадраў, тэгаў, працягласцей і каардынат кропак апоры ў фармаце, сумяшчальным з усімі сучаснымі 2D-рухавікамі.

### 10. 35 эрганамічных тэм і поўная лакалізацыя

- **Калекцыя тэм**: Studio Dark, Studio Light, Pitch Black, Cyberpunk Neon, Synthwave, Nord Frost, Dracula, Tokyo Night, Catppuccin Mocha, Gruvbox Dark, Monokai Pro, Solarized Dark, Solarized Light, люмінафоры CRT (Amber, Green, Cyan), рэтра-кансолі (Game Boy, Game Boy Light, Super Game Boy, NES/Famicom, SNES, Genesis/Mega Drive, PlayStation 1, PlayStation 2, Dreamcast) і рэтра-ПК (C64, ZX Spectrum, Amiga Workbench, Atari ST, MSX, Apple II, DOS CGA, Mac Classic, Windows 98).

### Зборка з зыходнага кода

#### Неабходныя кампаненты
- **Rust Toolchain**: Усталюйце інструменты Rust (рэкамендуецца версія 1.80+) праз [rustup.rs](https://rustup.rs/):
  ```bash
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  ```
- **Залежнасці для зборкі на Linux** (Debian/Ubuntu):
  ```bash
  sudo apt-get update
  sudo apt-get install -y build-essential pkg-config libxcb-render0-dev libxcb-shape0-dev \
    libxcb-xfixes0-dev libxkbcommon-dev libxkbcommon-x11-dev libssl-dev libgtk-3-dev libgl1-mesa-dev
  ```

#### 1. Кампіляцыя і запуск натыўнай дэсктопнай версіі
```bash
# Кланаванне рэпазіторыя
git clone https://github.com/rbm13s/OniAnvil.git
cd OniAnvil

# Запуск тэставага набору
cargo test

# Зборка і запуск аптымізаванага рэлізу
cargo run --release
```

#### 2. Кампіляцыя версіі WebAssembly (праз Trunk)
```bash
# Даданне мэтавай платформы wasm32 і зборшчыка Trunk
rustup target add wasm32-unknown-unknown
cargo install --locked trunk

# Запуск лакальнага dev-сервера з гарачай перазагрузкай
trunk serve

# Зборка аптымізаванага выпуску ў docs/app/
./build_wasm.sh        # Для Linux/macOS
./build_wasm.ps1       # Для Windows PowerShell
```

## Фармат файлаў і архітэктура праекта

OniAnvil не выкарыстоўвае закрытых двайковых фарматаў. Кожны праект захоўваецца ў выглядзе двух файлаў пад кантролем версій:

```
my_character/
├── my_character.png            # Стандартны PNG-атлас (адкрываецца ў любым рухавіку або рэдактары)
└── my_character.onianvil.json   # Файл метададзеных праекта
```

Файл метададзеных `.onianvil.json` змяшчае:
- Канфігурацыю сеткі палатна: памеры кадраў, колькасць калонак, агульную колькасць кадраў.
- Іерархію пластоў: назвы дарожак, узроўні празрыстасці, сцяжкі бачнасці і блакіроўкі.
- Анімацыйныя тэгі: назву, пачатковы і канчатковы кадры, кірунак прайгравання (Forward, Reverse, Ping-Pong), працягласць кадраў.
- Вызначэнні палітры: актыўныя колеры, спіс імянных скінаў, індэкс актыўнага скіна.
- Стан пласта эскіза: шлях да файла, маштаб, зрушэнне, вугал павароту, празрыстасць, рэжым пласта.
- Кропкі апоры: цэнтр спрайта (Pivot), кропкі мацавання зброі і гульнявыя маркеры калізій.
