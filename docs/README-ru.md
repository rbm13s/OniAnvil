## Введение

**OniAnvil** (*название образовано от **Oni**on-Skinning (покадровая калька) + **Anvil** (наковальня для ковки спрайтов)*) — это открытый высокопроизводительный редактор пиксельной графики и анимации, написанный на языке Rust. Приложение запускается нативно с аппаратным ускорением графики на Windows, Linux и macOS, а также работает прямо в браузере через WebAssembly без необходимости установки.

В отличие от классических редакторов, где анимация воспринимается как набор разрозненных файлов, требующих последующей нарезки и сборки в атлас, **OniAnvil изначально ставит в центр атлас спрайтшита (`atlas_rgba`)**. Ячейки кадров, слои, теги и точки привязки постоянно синхронизированы с общей текстурной картой.

### Почему OniAnvil?
- 🚀 **Молниеносная скорость Rust**: мгновенный старт, отрисовка без задержек на базе `wgpu` и `egui 0.31`, плавный скроллинг длинных таймлайнов.
- 🎬 **Монтажный многодорожечный таймлайн**: дорожки слоёв (`V1, V2, V3...`) с наложением сверху вниз, слиянием, связанными кадрами и множителями длительности.
- 🧅 **Первоклассный Onion Skinning**: калькирование соседних кадров с настраиваемыми цветами подсветки (красный/синий), плавным затуханием прозрачности и зацикливанием.
- 🎨 **Мгновенные скины персонажей**: создание цветовых вариаций (день/ночь, команды, стихии) за счёт аппаратного свопа палитр прямо в атласе.
- 📦 **Готовность к игровым движкам**: экспорт PNG с экструзией краевых пикселей (защита от швов фильтрации в 2D-движках, таких как Godot), GIF-анимаций и метаданных Sprite Sheet JSON.

## Функциональная документация

### 1. Атлас как единый источник истины

В OniAnvil текстурный атлас спрайтшита (`atlas_rgba`) является базовой сущностью, которая напрямую попадает в движок:
- **Frame Mode**: Фокусировка на одном активном кадре для точного рисования. Все изменения моментально отображаются в соответствующей ячейке атласа.
- **Atlas Mode**: Просмотр и редактирование всего листа спрайтов целиком для макро-контроля и пакетных операций.
- **Файл-компаньон**: Проекты сохраняются в виде чистого файла изображения `.png` и прозрачного мета-файла `.onianvil.json` со структурой слоёв, тегов, палитр и опорных точек.

### 2. Многодорожечный таймлайн слоёв

Нижний таймлайн спроектирован по принципам профессиональных видеоредакторов:
- **Дорожки слоёв (`V1, V2, V3...`)**: Слои отображаются сверху вниз. Дорожка, расположенная выше (`V1`), рисуется поверх нижних дорожек.
- **Управление слоями**:
  - Клик по плашкам `V1` / `V2` для быстрого переключения слоя рисования.
  - Переключение видимости (глаз) и блокировки от изменений (замок).
  - Регулировка прозрачности слоя (`0%..=100%`).
  - Перемещение вверх/вниз, дублирование и слияние со слоем ниже (Merge Down).
  - Безопасное удаление слоя с диалогом подтверждения.
- **Кадры и клипы**:
  - Множитель длительности (Hold): замедление отдельных фаз (например, `2×`, `3×` для пауз перед ударом).
  - Связанные кадры (`🔗`): многократное повторение кадра в таймлайне, при котором правка одного экземпляра мгновенно обновляет все остальные.
  - Анимационные теги: разделение анимации на именованные блоки (`idle`, `walk`, `attack`) с цикличным воспроизведением.
  - Управление воспроизведением: Вперёд, Назад, Пинг-понг и Зацикливание со скоростью от `1` до `120` FPS.

### 3. Живой предпросмотр анимации в реальном времени

Правая док-панель Preview воспроизводит анимацию с заданной частотой кадров без привязки к масштабу и положению основного холста:
- **Фильтрация тегов**: Запуск только выбранного тега (`walk`) или всей цепочки кадров.
- **Управление скоростью**: Кнопки Play, Pause, покаговый переход, зацикливание и множители скорости (`0.25x..=4.0x`).
- **Фоны просмотра**: Быстрое переключение шахматки, светлого фона, тёмного фона или прозрачности.

### 4. Продвинутая система кальки (Onion Skinning)

- **Раздельная подсветка**: Независимый выбор цвета для предыдущих кадров (по умолчанию красный) и следующих кадров (по умолчанию синий).
- **Кривая затухания**: Настройка начальной прозрачности и шага затухания для каждого последующего шага кальки.
- **Зацикливание**: Подсветка первого кадра сквозь последний при создании бесшовных циклов.
- **Быстрый просмотр (Quick-Peek)**: Удержание клавиши <kbd>Пробел</kbd> без перемещения мыши мгновенно подсвечивает соседние кадры.

### 5. Слой эскизов и обводки референсов

- **Форматы**: Загрузка референсов и эскизов в форматах PNG, JPEG и WebP.
- **Режимы наложения**: Подложка (под пиксельными слоями) или Наложение (поверх холста).
- **Трансформация**: Независимый зум, позиционирование, вращение и прозрачность.
- **Умная пипетка**: Забор цвета с эскиза с автоматическим притяжением к ближайшему цвету активной палитры проекта.
- **Запекание (1-Click Bake)**: Превращение масштабированного эскиза в чистый пиксель-арт на активном кадре одним кликом.

### 6. Высокоточное выделение и «бегающие мурашки»

- **Динамический контур**: Контур активного выделения анимируется двухцветными контрастными бегающими штрихами (как в Photoshop/Aseprite).
- **Сплошное полигональное лассо**: В отличие от стандартных алгоритмов луча, создающих «дыры» на пересекающихся петлях, лассо OniAnvil строит замкнутый 8-связный контур и заливает внешнее пространство, гарантируя 100% сплошное заполнение внутри.
- **Операции с выделением**: Расширение, Сжатие, Граница (с круглой, квадратной или ромбовидной формой ядра), Перемещение, Инвертирование, Удаление и Свободный поворот.
- **Сквозной буфер обмена между кадрами**: Выделив область на одном кадре и нажав <kbd>Ctrl/Cmd+C</kbd>, можно переключиться на любой другой кадр и нажать <kbd>Ctrl/Cmd+V</kbd> — пиксели вставятся точно по координатам на любой языковой раскладке клавиатуры.

### 7. Живые эффекты, фильтры и RotSprite

Все эффекты снабжены чекбоксом **Предпросмотр (Live Preview)**, отображающим результат прямо на кадре до применения и не засоряющим историю отмен при отказе:
- **Замена цвета (`Shift+R`)**:
  - Интерактивная пипетка: выбор заменяемого и целевого цветов кликом по пикселям холста или плашкам палитры.
  - Полоса быстрой палитры: ЛКМ выбирает цвет «Из», ПКМ выбирает цвет «В».
  - Ползунок допуска (Tolerance) и пакетная замена сразу по всем кадрам анимации.
- **Цветокоррекция HSV (`Ctrl/Cmd+U`)**: Сдвиг тона (Hue), Насыщенности (Saturation), Яркости (Value) и Контраста.
- **Генератор контура**: Создание пиксельного контура персонажа (Внаружи, Внутри, По центру) со скошенными (ромб) или прямыми (квадрат) углами.
- **Матричные фильтры 3×3**: Размытие, Повышение резкости, Выделение границ и Тиснение с сохранением альфа-канала.
- **Свободный поворот (`Ctrl/Cmd+Shift+R`)**: Поворот области или кадра на произвольный угол алгоритмом **RotSprite** или Nearest Neighbor.
- **Привязка к палитре**: Пересчёт изображения в цвета палитры с дизерингом Байера (2x2, 4x4, 8x8) или Blue Noise.

### 8. Управление палитрами, своп и скины персонажей

- **Встроенные палитры**: 25+ ретро-палитр (DawnBringer DB8/DB16/DB32, Windows 95, Game Boy, PICO-8, Commodore 64, NES, Endesga 32, Solarized, Sweetie 16).
- **Импорт и экспорт**: Поддержка файлов GIMP Palette (`.gpl`), JASC PAL (`.pal`), Hex (`.hex`) и графических полос (`.png`).
- **Своп палитр (Скины)**: Создание нескольких цветовых версий одного персонажа (например, Обычный, Золотая броня, Тень, Лёд) с мгновенным пересчётом всех кадров атласа.
- **Генератор цветовых рамп**: Автоматическое построение плавных градиентных переходов между двумя заданными оттенками с настраиваемым числом ступеней.

### 9. Нарезчик листов, 9-Grid UI и экспорт для игровых движков

- **Sheet Slicer**: Алгоритм автокорреляции контуров автоматически нарезает готовые спрайтшиты на ровные кадры анимации.
- **9-Grid (9-Slice)**: Настройка масштабируемых полей элементов интерфейса (окна, кнопки, диалоговые панели) без искажения углов.
- **Экспорт PNG с экструзией краевых пикселей**: Дублирование пикселей по границам тайлов предотвращает швы и артефакты билинейной фильтрации на текстурах в OpenGL, DirectX, Vulkan и Godot Engine.
- **Экспорт анимированных GIF**: Оптимизированный энкодер с поддержкой прозрачности и циклов.
- **Стандартный Sprite Sheet JSON**: Экспорт координат кадров, длительностей и точек привязки в стандартном формате современных игровых движков.

### 10. 35 эргономичных тем и полная локализация

- **Коллекция тем**: Studio Dark, Studio Light, Pitch Black, Cyberpunk Neon, Synthwave, Nord Frost, Dracula, Tokyo Night, Catppuccin Mocha, Gruvbox Dark, Monokai Pro, Solarized Dark, Solarized Light, CRT-люминофоры (Amber, Green, Cyan), Ретро-консоли (Game Boy, Game Boy Light, Super Game Boy, Famicom/NES, SNES, Genesis/Mega Drive, PlayStation 1, PlayStation 2, Dreamcast) и Ретро-ПК (C64, ZX Spectrum, Amiga Workbench, Atari ST, MSX, Apple II, DOS CGA, Mac Classic, Windows 98).
- **Двуязычный интерфейс**: Переключение между **Русским** и **English** языками на лету со 100% паритетом всех строк и подсказок.

Загрузите готовые автономные исполняемые файлы со **[страницы релизов GitHub](https://github.com/rbm13s/OniAnvil/releases/latest)**:

Для комфортной и регулярной работы настоятельно рекомендуется использовать нативные десктопные версии.

# Клонирование репозитория
git clone https://github.com/rbm13s/OniAnvil.git
cd OniAnvil

# Запуск тестов
cargo test

# Сборка и запуск оптимизированного релиза
cargo run --release
```

# Добавление целевой платформы wasm32 и сборщика Trunk
rustup target add wasm32-unknown-unknown

./build_wasm.sh        # Для Linux/macOS

```

## Формат файлов и архитектура проекта

OniAnvil не использует закрытые проприетарные форматы. Проект сохраняется в виде двух файлов под версионным контролем:

```
my_character/
├── my_character.png            # Стандартный PNG-атлас (открывается в любом движке и редакторе)
└── my_character.onianvil.json   # JSON-файл метаданных проекта
```

Файл `.onianvil.json` содержит:
- Сетку атласа: размеры кадра, число колонок, общее количество кадров.
- Иерархию слоёв: имена дорожек, прозрачность, флаги видимости и блокировки.
- Теги анимации: имя, начальный/конечный кадры, направление воспроизведения, длительности.
- Палитры: активные цвета, список именованных скинов, индекс активного скина.
- Слой эскиза: путь к картинке, масштаб, смещение, угол поворота, прозрачность.
- Опорные точки: центр спрайта (Pivot) и пользовательские точки событий (Action Points).
