## Εισαγωγή

Το **OniAnvil** (*προέρχεται από το **Oni**on-Skinning (διαφάνεια καρέ) + **Anvil** (αμόνι σφυρηλάτησης sprite)*) είναι ένα λογισμικό ανοιχτού κώδικα υψηλής απόδοσης για σχεδιασμό εικονοστοιχείων (pixel art) και δημιουργία κινούμενων σχεδίων, γραμμένο στη γλώσσα Rust. Εκτελείται εγγενώς με επιτάχυνση υλικού σε Windows, Linux και macOS, καθώς και ως εφαρμογή WebAssembly χωρίς ανάγκη εγκατάστασης απευθείας σε σύγχρονα προγράμματα περιήγησης ιστού.

Τα περισσότερα παραδοσιακά προγράμματα επεξεργασίας αντιμετωπίζουν τα κινούμενα σχέδια ως μια στοίβα ασύνδετων αρχείων εικόνας, εξαναγκάζοντας τους δημιουργούς σε επίπονες διαδικασίες εξαγωγής, τεμαχισμού και επανασυσκευασίας. **Το OniAnvil ανατρέπει αυτό το υπόδειγμα:** η υφή του άτλαντα sprite sheet του παιχνιδιού (`atlas_rgba`) αποτελεί τη μόνη πρωταρχική πηγή αλήθειας (source of truth). Τα κελιά των καρέ, τα κανάλια επιπέδων, οι ετικέτες κίνησης και τα σημεία περιστροφής/σύγκρουσης διατηρούνται πάντα συγχρονισμένα με τον άτλαντα χωρίς απώλειες.

### Γιατί OniAnvil;
- 🚀 **Αστραπιαία εγγενής απόδοση Rust**: Στιγμιαία εκκίνηση κάτω του χιλιοστού του δευτερολέπτου, κρυστάλλινη απόδοση χάρη στο `wgpu` και το `egui 0.31`, και μηδενική καθυστέρηση κατά την κύλιση μεγάλων χρονολογίων.
- 🎬 **Χρονολόγιο πολλαπλών καναλιών επιπέδων**: Κανάλια επιπέδων εμπνευσμένα από επαγγελματικό λογισμικό μοντάζ (`V1, V2, V3...`) με σύνθεση από πάνω προς τα κάτω, συγχώνευση προς τα κάτω, συνδεδεμένα καρέ και προσαρμόσιμους πολλαπλασιαστές διάρκειας (hold).
- 🧅 **Onion Skinning πρώτης κατηγορίας**: Εμφάνιση ειδώλων πολλαπλών καρέ με ανεξάρτητο χρωματισμό προηγούμενων/επόμενων καρέ, προσαρμόσιμες καμπύλες διαφάνειας και υποστήριξη συνεχούς βρόχου.
- 🎨 **Άμεση δημιουργία αμφιέσεων παλέτας χαρακτήρων**: Δημιουργήστε παραλλαγές ημέρας/νύχτας, ομαδικά χρώματα ή στοιχειώδεις αμφιέσεις με ζωντανή επαναχαρτογράφηση άτλαντα και εισαγωγή/εξαγωγή μορφών GPL, PAL και HEX.
- 📦 **Άμεση εξαγωγή για μηχανές παιχνιδιών**: Εξαγωγή κλιμακωμένων PNG με εκτεταμένα περιθώρια (extrusion) για εξάλειψη ατελειών φιλτραρίσματος υφών σε 2D μηχανές (Godot, Bevy, Raylib, Defold), μαζί με πρότυπα μεταδεδομένα Sprite Sheet JSON και κινούμενα GIF.

## Πλήρης οδηγός εργαλείων

Το OniAnvil περιλαμβάνει 15 εργαλεία σχεδίασης, γεωμετρικών σχημάτων, επιλογής και μεταδεδομένων ακριβείας. Τα εικονίδια αποδίδονται με τη χρήση της σουίτας **Font Awesome Free** *(Εικονίδια: CC BY 4.0, Γραμματοσειρές: SIL OFL 1.1)*.

| Εργαλείο | Εικονίδιο | Συντόμευση | Μέγεθος πινέλου | Pixel Perfect | Περιγραφή |
|:---|:---:|:---:|:---:|:---:|:---|
| **Μολύβι** | ✏️ | <kbd>B</kbd> | 1..32 px | Ναι | Κύριο εργαλείο σχεδίασης. Η λειτουργία 1px υποστηρίζει **Pixel-Perfect** (αφαιρεί αυτόματα τις αντιαισθητικές γωνίες σχήματος L). Υποστηρίζει προσαρμοσμένα πινέλα-σφραγίδες από επιλογή (`Ctrl/Cmd+B`). |
| **Γόμα** | 🧹 | <kbd>E</kbd> | 1..32 px | Όχι | Διαγράφει εικονοστοιχεία σε πλήρη διαφάνεια (`[0, 0, 0, 0]`). Περιορίζεται αυστηρά εντός της ενεργής επιλογής αν υπάρχει μάσκα. |
| **Σταγονόμετρο** | 💉 | <kbd>I</kbd> / <kbd>Alt</kbd> | 1 px | Όχι | Το αριστερό κλικ επιλέγει χρώμα Προσκηνίου (Foreground), το δεξί κλικ χρώμα Φόντου (Background). Δειγματοληψία από καμβά, επίπεδα ή σχέδιο αναφοράς. |
| **Κουβάς βαφής** | 🪣 | <kbd>G</kbd> | N/A | Όχι | Γρήγορο γέμισμα βασισμένο σε ουρά (BFS) με ρυθμιζόμενο όριο ανοχής χρωμάτων (`0..=255`). Υποστηρίζει συνεχόμενη ή καθολική λειτουργία και περιορισμό εντός επιλογής. |

## Λειτουργική τεκμηρίωση

### 1. Διπλή αρχιτεκτονική με επίκεντρο τον άτλαντα

Στο OniAnvil, ο κύριος άτλαντας υφών (`atlas_rgba`) αντιπροσωπεύει την πραγματική υφή του φύλλου sprite όπως φορτώνεται από τη μηχανή παιχνιδιού σας.
- **Λειτουργία καρέ (Frame Mode)**: Εστιάζει σε ένα ενεργό καρέ κίνησης, παρέχοντας έναν καθαρό καμβά σχεδίασης. Οι αλλαγές ενημερώνουν άμεσα το αντίστοιχο κελί στην υφή του άτλαντα.
- **Λειτουργία άτλαντα (Atlas Mode)**: Εμφανίζει ολόκληρο το πλέγμα του sprite sheet, επιτρέποντας μακροσκοπικές ρυθμίσεις, ελέγχους ευθυγράμμισης μεταξύ των καρέ και μαζική επεξεργασία.
- **Συνοδευτικό αρχείο (Companion File)**: Τα έργα αποθηκεύουν καθαρά sprite sheets μορφής `.png` συνοδευόμενα από ένα ελαφρύ αρχείο `.onianvil.json` που περιέχει διατάξεις καρέ, ιεραρχίες επιπέδων, ετικέτες, πολλαπλασιαστές διάρκειας και αμφιέσεις παλέτας.

### 2. Χρονολόγιο πολλαπλών καναλιών επιπέδων

Το κάτω χρονολόγιο έχει σχεδιαστεί κατά τα πρότυπα επαγγελματικού λογισμικού μη γραμμικής επεξεργασίας βίντεο:
- **Κανάλια επιπέδων (`V1, V2, V3...`)**: Τα επίπεδα διατάσσονται οπτικά από πάνω προς τα κάτω. Το κανάλι που βρίσκεται ψηλότερα στο χρονολόγιο (`V1`) αποδίδεται επάνω στον καμβά του καρέ.
- **Χειριστήρια καναλιών**:
  - Κάντε κλικ στα σήματα `V1` / `V2` για γρήγορη αλλαγή του ενεργού επιπέδου σχεδίασης.
  - Εναλλαγή ορατότητας (εικονίδιο ματιού) και κλειδώματος επιπέδου (εικονίδιο λουκέτου).
  - Ρύθμιση αδιαφάνειας επιπέδου (`0%..=100%`).
  - Μετακίνηση πάνω/κάτω στην ιεραρχία, διπλασιασμός επιπέδου και συγχώνευση στο υποκείμενο κανάλι (Merge Down).
  - Ασφαλής διαγραφή επιπέδου με παράθυρο επιβεβαίωσης.
- **Κλιπ καρέ**:
  - Πολλαπλασιαστής διάρκειας (Hold): εκχώρηση προσαρμοσμένης διάρκειας καρέ (π.χ. `2×`, `3×` κράτημα για παύσεις ή στιγμές πρόσκρουσης).
  - Συνδεδεμένα καρέ: σύνδεση επαναλαμβανόμενων φάσεων στην κίνηση, ώστε η επεξεργασία ενός να ενημερώνει αυτόματα όλα τα συνδεδεμένα στιγμιότυπα.
  - Βρόχοι ετικετών: οργάνωση κινήσεων σε επώνυμες ετικέτες (`idle`, `walk`, `attack`) και επανάληψη συγκεκριμένων ετικετών κατά την αναπαραγωγή.
  - Χειριστήρια αναπαραγωγής: Εμπρός, Πίσω, Πινγκ-Πονγκ και Συνεχής βρόχος με ρυθμιζόμενο ρυθμό καρέ (`1..=120` FPS).

### 3. Ζωντανή προεπισκόπηση κινούμενων σχεδίων σε πραγματικό χρόνο

Ο δεξιός πίνακας προεπισκόπησης αναπαράγει τα κινούμενα σχέδιά σας σε πραγματικό χρόνο, ανεξάρτητα από το ζουμ ή τη μετατόπιση του κύριου καμβά:
- **Φιλτράρισμα ετικετών**: Απομόνωση αναπαραγωγής σε συγκεκριμένες ετικέτες (`walk`, `jump`) ή προεπισκόπηση ολόκληρης της αλληλουχίας.
- **Χειριστήρια αναπαραγωγής**: Αναπαραγωγή, Παύση, Προηγούμενο βήμα, Επόμενο βήμα, Εναλλαγή βρόχου και προσαρμοσμένες ταχύτητες αναπαραγωγής (`0.25x..=4.0x`).
- **Λειτουργίες εμφάνισης**: Εναλλαγή μεταξύ σκούρας σκακιέρας, ανοιχτής σκακιέρας, καθαρού λευκού, απόλυτου μαύρου ή προσαρμοσμένων φόντων.

### 4. Προηγμένη μηχανή Onion Skinning

Δημιουργήστε ρευστά κινούμενα σχέδια χρησιμοποιώντας το εξειδικευμένο σύστημα onion skinning:
- **Προσαρμοσμένος χρωματισμός**: Ανεξάρτητα χρώματα απόχρωσης για τα προηγούμενα καρέ (προεπιλογή: Κόκκινο) και τα επόμενα καρέ (προεπιλογή: Μπλε).
- **Καμπύλη εξασθένησης αδιαφάνειας**: Ρυθμιζόμενη βασική αδιαφάνεια και βαθμιαία μείωση ανά βήμα διαφάνειας.
- **Κυκλική αναδίπλωση**: Ενεργοποίηση εμφάνισης ειδώλου μεταξύ του πρώτου και του τελευταίου καρέ σε κυκλικές κινήσεις.
- **Γρήγορη ματιά (Quick-Peek)**: Κρατήστε πατημένο το <kbd>Space</kbd> χωρίς σύρσιμο για άμεση προεπισκόπηση των γειτονικών καρέ.

### 5. Έξυπνο επίπεδο αναφοράς και ιχνηλάτησης σχεδίου

Επιταχύνετε τη ροή εργασίας σας ιχνηλατώντας σκίτσα στο χέρι ή φωτογραφίες αναφοράς:
- **Μορφές αρχείων**: Φόρτωση εικόνων αναφοράς PNG, JPEG και WebP.
- **Λειτουργίες ανάμειξης**: Υπόστρωμα (κάτω από τα επίπεδα pixel) ή Επίστρωμα (πάνω από τα επίπεδα pixel).
- **Χειριστήρια μετασχηματισμού**: Ανεξάρτητο ζουμ, μετατόπιση θέσης, περιστροφή και ολισθητής διαφάνειας.
- **Έξυπνη δειγματοληψία χρώματος**: Χρησιμοποιήστε το Σταγονόμετρο στο επίπεδο σκίτσου με προαιρετική αυτόματη προσκόλληση στο πλησιέστερο χρώμα της ενεργής παλέτας.
- **Αποτύπωση με 1 κλικ (1-Click Bake)**: Μετατρέψτε την κλιμακωμένη εικόνα αναφοράς απευθείας σε pixel art στο ενεργό καρέ.

### 6. Σουίτα επιλογής ακριβείας και «μυρμήγκια σε πορεία»

- **Κινούμενα μυρμήγκια σε πορεία**: Οι ενεργές επιλογές εμφανίζουν κινούμενα, υψηλής αντίθεσης διακεκομμένα περιγράμματα διπλού τόνου.
- **Συμπαγής επιλογή λάσο με γέμισμα**: Σε αντίθεση με απλοϊκούς αλγορίθμους ακτίνων που αφήνουν κενά σε επικαλυπτόμενους βρόχους, το λάσο του OniAnvil ραστεροποιεί ένα κλειστό 8-συνδεδεμένο όριο και γεμίζει το εξωτερικό, εξασφαλίζοντας 100% συμπαγείς επιλογές χωρίς κενά.
- **Λειτουργίες επιλογής**: Επέκταση, Συρρίκνωση, Περίγραμμα (με σχήματα πυρήνα Κύκλου, Τετραγώνου και Ρόμβου), Μετατόπιση, Αντιστροφή, Διαγραφή, Ελεύθερη περιστροφή και Αντιγραφή/Αποκοπή/Επικόλληση προχείρου συστήματος.
- **Αντιγραφή και επικόλληση μεταξύ καρέ**: Επιλέξτε περιοχές σε ένα καρέ, πατήστε <kbd>Ctrl/Cmd+C</kbd>, αλλάξτε καρέ και πατήστε <kbd>Ctrl/Cmd+V</kbd> για επικόλληση στις ακριβείς συντεταγμένες σε οποιαδήποτε διάταξη πληκτρολογίου.

### 7. Ζωντανά εφέ, φίλτρα και RotSprite

Όλα τα εφέ εικόνας περιλαμβάνουν πλαίσιο ελέγχου **Ζωντανής προεπισκόπησης (Live Preview)** που απεικονίζει τις αλλαγές στον καμβά και επιτρέπει ακύρωση χωρίς να επιβαρύνεται το ιστορικό αναιρέσεων:
- **Αντικατάσταση χρώματος (`Shift+R`)**:
  - Διαδραστικό σταγονόμετρο: κάντε κλικ στο εικονίδιο πιπέτας και επιλέξτε χρώματα απευθείας από τα εικονοστοιχεία ή την παλέτα.
  - Λωρίδα γρήγορης επιλογής: αριστερό κλικ για επιλογή χρώματος «Από», δεξί κλικ για χρώμα «Σε».
  - Ολισθητήρας ανοχής και μαζική αντικατάσταση σε όλα τα καρέ της κίνησης.
- **Ρύθμιση χρώματος (`Ctrl/Cmd+U`)**: Ρύθμιση απόχρωσης HSV (Hue), κορεσμού (Saturation), φωτεινότητας (Value) και αντίθεσης σε πραγματικό χρόνο.
- **Αυτόματη γεννήτρια περιγράμματος**: Δημιουργήστε καθαρά περιγράμματα χαρακτήρων (Εξωτερικό, Εσωτερικό, Κεντραρισμένο) με τετράγωνες ή ρομβοειδείς ενώσεις γωνιών.
- **Φίλτρα πίνακα 3×3**: Φίλτρα θόλωσης, όξυνσης, ανίχνευσης ακμών και ανάγλυφου με διατήρηση του καναλιού άλφα.
- **Ελεύθερη περιστροφή (`Ctrl/Cmd+R`)**: Περιστρέψτε επιλεγμένες περιοχές ή ολόκληρα καρέ σε οποιαδήποτε γωνία χρησιμοποιώντας τους κλασικούς αλγορίθμους **RotSprite** ή Nearest Neighbor.
- **Επαναχαρτογράφηση σε παλέτα**: Μετατρέψτε τα χρώματα του καμβά στην ενεργή παλέτα χρησιμοποιώντας διασπορά Bayer 2x2, 4x4, 8x8 ή Blue Noise.

### 8. Διαχείριση παλετών, εναλλαγή και αμφιέσεις χαρακτήρων

- **Ενσωματωμένες παλέτες**: Πάνω από 20 αυθεντικές ρετρό παλέτες όπως Game Boy, PICO-8, Commodore 64, NES, Endesga 32, Solarized και Sweetie 16.
- **Εισαγωγή και εξαγωγή**: Υποστήριξη για παλέτες GIMP (`.gpl`), PAL (`.pal`), δεκαεξαδικές (`.hex`) και λωρίδες εικόνας (`.png`).
- **Εναλλαγή παλετών (Αμφιέσεις / Skins)**: Ορίστε πολλαπλές χρωματικές παραλλαγές για έναν μόνο χαρακτήρα (π.χ. Προεπιλογή, Χρυσή Πανοπλία, Σκιά, Παγωμένος). Η εναλλαγή αμφίεσης επαναχαρτογραφεί άμεσα όλα τα χρώματα των καρέ σε ολόκληρο τον άτλαντα.
- **Γεννήτρια χρωματικών διαβαθμίσεων**: Αυτόματη παρεμβολή ομαλών διαβαθμίσεων μεταξύ δύο επιλεγμένων αποχρώσεων με ρυθμιζόμενο αριθμό ενδιάμεσων βημάτων.

### 9. Τεμαχιστής φύλλων, διεπαφή 9-Grid και εξαγωγή για μηχανές παιχνιδιών

- **Τεμαχιστής φύλλων (Sheet Slicer)**: Η ανίχνευση ορίων αυτοσυσχέτισης τεμαχίζει αυτόματα ακατέργαστα φύλλα sprite σε ομοιόμορφα ή σφιχτά οριοθετημένα καρέ κίνησης.
- **Κλιμάκωση 9-Grid (9-Slice)**: Ορίστε προσαρμόσιμα περιθώρια τεμαχισμού (πάνω, κάτω, αριστερά, δεξιά) για προεπισκόπηση κλιμακούμενων πλαισίων διεπαφής χρήστη χωρίς παραμόρφωση γωνιών.
- **Εξαγωγή PNG με εκτεταμένα περιθώρια (Extrusion)**: Επεκτείνει τα χρώματα των ακραίων εικονοστοιχείων στα διαφανή περιθώρια, εξαλείφοντας τις ανεπιθύμητες γραμμές φιλτραρίσματος σε OpenGL, DirectX, Vulkan και μηχανές 2D (όπως το Godot).
- **Εξαγωγή κινούμενου GIF**: Βελτιστοποιημένη δημιουργία GIF με προσαρμοσμένο αριθμό βρόχων, καθυστερήσεις καρέ και διαφανές φόντο.
- **Πρότυπο Sprite Sheet JSON**: Εξάγει συντεταγμένες καρέ, ετικέτες, διάρκειες και σημεία περιστροφής σύμφωνα με το πρότυπο σχήμα JSON σύγχρονων 2D μηχανών.

### 10. 35 εργονομικά θέματα και πλήρης τοπικοποίηση

- **Επιλεγμένα θέματα**: Studio Dark, Studio Light, Pitch Black, Cyberpunk Neon, Synthwave, Nord Frost, Dracula, Tokyo Night, Catppuccin Mocha, Gruvbox Dark, Monokai Pro, Solarized Dark, Solarized Light, Φωσφόροι CRT (Amber, Green, Cyan), Ρετρό κονσόλες (Game Boy, Game Boy Light, Super Game Boy, NES/Famicom, SNES, Genesis/Mega Drive, PlayStation 1, PlayStation 2, Dreamcast) και Ρετρό υπολογιστές (C64, ZX Spectrum, Amiga Workbench, Atari ST, MSX, Apple II, DOS CGA, Mac Classic, Windows 98).
- **Πλήρης τοπικοποίηση**: Απρόσκοπτη εναλλαγή μεταξύ 37 υποστηριζόμενων γλωσσών με 100% ισοτιμία κλειδιών λεξικού και φυσικές μεταφράσεις.

Κατεβάστε προγλωττισμένα, αυτοτελή εκτελέσιμα αρχεία από τη **[Σελίδα εκδόσεων GitHub](https://github.com/rbm13s/OniAnvil/releases/latest)**:

- **Linux**: Κατεβάστε το `OniAnvil-linux-x86_64.tar.gz` (φορητό) ή εγκαταστήστε το πακέτο Debian/Ubuntu `onianvil_*_amd64.deb`:
  ```bash
  sudo dpkg -i onianvil_*_amd64.deb
  ```
- **macOS**: Κατεβάστε το `OniAnvil-macos-universal.zip`, εξαγάγετε το και σύρετε το `OniAnvil.app` στο φάκελο Εφαρμογές. Το καθολικό δυαδικό αρχείο εκτελείται εγγενώς τόσο σε υπολογιστές Apple Silicon (M1/M2/M3/M4) όσο και σε Intel Mac.
- **Web**: Εκτελέστε απευθείας στο πρόγραμμα περιήγησής σας χωρίς εγκατάσταση: **[Άνοιγμα εφαρμογής WebAssembly](https://rbm13s.github.io/OniAnvil/app/?lang=el)**.
  > [!WARNING]
  > Η έκδοση WebAssembly (περιηγητής) έχει **Πειραματικό (Experimental)** χαρακτήρα. Λόγω περιορισμών της δοκιμαστικής περιοχής (sandbox) του προγράμματος περιήγησης, διαφορών WebGL/WebGPU και περιορισμών προχείρου, ενδέχεται να αντιμετωπίσετε μικρά γραφικά σφάλματα ή μειωμένη απόδοση σε σύγκριση με την εγγενή έκδοση για υπολογιστές γραφείου. Για επαγγελματική χρήση, συνιστώνται ανεπιφύλακτα οι εγγενείς εκδόσεις.

  ```bash
  sudo apt-get update
  sudo apt-get install -y build-essential pkg-config libxcb-render0-dev libxcb-shape0-dev \
    libxcb-xfixes0-dev libxkbcommon-dev libxkbcommon-x11-dev libssl-dev libgtk-3-dev libgl1-mesa-dev
  ```

#### 1. Μεταγλώττιση & εκτέλεση εγγενούς έκδοσης
```bash
# Κλωνοποίηση του αποθετηρίου
git clone https://github.com/rbm13s/OniAnvil.git
cd OniAnvil

# Εκτέλεση σουίτας δοκιμών
cargo test

# Μεταγλώττιση και εκτέλεση βελτιστοποιημένης έκδοσης
```

```bash

cargo install --locked trunk

# Εκτέλεση τοπικού διακομιστή ανάπτυξης με αυτόματη ανανέωση
trunk serve

# Δημιουργία βελτιστοποιημένων αρχείων έκδοσης στο docs/app/
./build_wasm.sh        # Σε Linux/macOS
./build_wasm.ps1       # Σε Windows PowerShell
```

## Μορφή αρχείων και συνοδευτική αρχιτεκτονική

Το OniAnvil αποφεύγει ιδιόκτητες δυαδικές μορφές. Κάθε έργο αποτελείται από δύο καθαρά αρχεία που μπορούν να τεθούν υπό έλεγχο εκδόσεων (Git):

```
my_character/
├── my_character.png            # Τυπικός άτλαντας sprite sheet PNG (ανοίγει σε οποιαδήποτε μηχανή ή πρόγραμμα προβολής)
└── my_character.onianvil.json   # Συνοδευτικό αρχείο μεταδεδομένων JSON
```

Το συνοδευτικό αρχείο `.onianvil.json` αποθηκεύει:
- Ρυθμίσεις πλέγματος καμβά: διαστάσεις καρέ, αριθμός στηλών, συνολικός αριθμός καρέ.
- Ιεραρχίες επιπέδων: ονόματα καναλιών, επίπεδα αδιαφάνειας, δείκτες ορατότητας, καταστάσεις κλειδώματος.
- Ετικέτες κίνησης: όνομα, δείκτες αρχικού/τελικού καρέ, κατεύθυνση αναπαραγωγής (Εμπρός, Πίσω, Πινγκ-Πονγκ), διάρκειες καρέ.
- Ορισμούς παλετών: ενεργά δείγματα χρωμάτων, επώνυμες παραλλαγές αμφιέσεων (skins), δείκτης ενεργής αμφίεσης.
- Κατάσταση σχεδίου αναφοράς: διαδρομή εικόνας, κλίμακα, μετατόπιση θέσης, περιστροφή, αδιαφάνεια, λειτουργία επιπέδου.
- Σημεία περιστροφής: προσαρμοσμένα σημεία δράσης, θέσεις τοποθέτησης όπλων και κέντρα σύγκρουσης.
