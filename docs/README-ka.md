## შესავალი

**OniAnvil** (*სახელწოდება მომდინარეობს **Oni**on-Skinning (კადრობრივი კალკა) + **Anvil** (სპრაიტების სამჭედლო გრდემლი)*) წარმოადგენს ღია კოდის მქონე, უმაღლესი წარმადობის პიქსელ-არტის რედაქტორსა და ანიმაციურ პაკეტს, რომელიც დაწერილია Rust-ზე. ის მუშაობს ნატიურად აპარატურულად აჩქარებული რენდერინგით Windows-ზე, Linux-სა და macOS-ზე, ასევე ინსტალაციის გარეშე პირდაპირ თანამედროვე ვებ-ბრაუზერებში WebAssembly-ის მეშვეობით.

ტრადიციული რედაქტორების უმეტესობა ანიმაციას განიხილავს, როგორც ცალკეული სურათების დასტას, რაც დეველოპერებს აიძულებს გაიარონ ექსპორტის, დაჭრისა და თავიდან აწყობის რუტინული ეტაპები. **OniAnvil ცვლის ამ მიდგომას:** თამაშის სპრაიტების ატლასის ტექსტურა (`atlas_rgba`) არის ჭეშმარიტების პირველადი და ერთადერთი წყარო (source of truth). კადრის უჯრები, ფენების ტრეკები, ანიმაციური ტეგები და შეჯახების/ღერძის წერტილები ყოველთვის დანაკარგების გარეშე ინარჩუნებენ სინქრონიზაციას ატლასთან.

### რატომ OniAnvil?
- 🚀 **Rust-ის ელვისებური სისწრაფე**: მყისიერი ჩატვირთვა მილიწამზე ნაკლებ დროში, სუფთა რენდერინგი `wgpu`-სა და `egui 0.31`-ის ბაზაზე, ნულოვანი დაყოვნება გრძელი ტაიმლაინების გადახვევისას.
- 🎬 **მრავალტრეკიანი ფენების ტაიმლაინი**: ვიდეო მონტაჟის პროგრამებით შთაგონებული ფენების ბილიკები (`V1, V2, V3...`) ზემოდან ქვემოთ კომპოზიციით, ფენების ქვემოთ შერწყმით, დაკავშირებული კადრებითა და შეკავების მამრავლებით.
- 🧅 **პირველი კლასის კალკა (Onion Skinning)**: მრავალკადრიანი მოჩვენების ეფექტი წინა და მომდევნო კადრების დამოუკიდებელი ტონირებით, მორგებადი გამჭვირვალობის მრუდებითა და ციკლური შეკვრით.
- 🎨 **პერსონაჟის პალიტრის მყისიერი სკინები**: შექმენით დღის/ღამის ვარიანტები, გუნდური ან სტიქიური სკინები ატლასის რეალურ დროში გადახატვით და GPL, PAL, HEX იმპორტ-ექსპორტით.
- 📦 **პირდაპირი ექსპორტი თამაშის ძრავებისთვის**: ექსპორტირებადი მასშტაბირებული PNG-ები გაფართოებული (ექსტრუდირებული) საზღვრებით ტექსტურების გაჟონვის (bleeding) აღმოსაფხვრელად 2D ძრავებში (Godot, Bevy, Raylib, Defold), სტანდარტულ Sprite Sheet JSON მეტამონაცემებთან და ანიმირებულ GIF-ებთან ერთად.

## ფუნქციური დოკუმენტაცია

### 1. ორმაგი ატლას-ცენტრული არქიტექტურა

OniAnvil-ში ტექსტურის მასტერ ატლასი (`atlas_rgba`) წარმოადგენს სპრაიტ-ფურცლის რეალურ ტექსტურას, ზუსტად ისე, როგორც მას ტვირთავს თამაშის ძრავა.
- **კადრის რეჟიმი (Frame Mode)**: ფოკუსირდება ერთ აქტიურ ანიმაციურ კადრზე, რაც უზრუნველყოფს სუფთა სამუშაო ტილოს. ცვლილებები მყისიერად აისახება ატლასის ტექსტურის შესაბამის უჯრაში.
- **ატლასის რეჟიმი (Atlas Mode)**: აჩვენებს მთელ სპრაიტ-ფურცელს, რაც იძლევა მაკრო-კონტროლის, კადრების გასწორებისა და ჯგუფური რედაქტირების საშუალებას.
- **კომპანიონი ფაილი (Companion File)**: პროექტები ინახება სუფთა `.png` სპრაიტ-ფურცლად და მსუბუქ `.onianvil.json` მეტამონაცემების ფაილად, რომელიც ინახავს ფენებს, ტეგებს, შეკავების კოეფიციენტებსა და პალიტრის სკინებს.

### 2. მრავალტრეკიანი ფენების ტაიმლაინი

ქვედა ტაიმლაინი აგებულია პროფესიონალური ვიდეო სამონტაჟო პროგრამების პრინციპებზე:
- **ფენების ტრეკები (`V1, V2, V3...`)**: ფენები ვიზუალურად განლაგებულია ზემოდან ქვემოთ. ტაიმლაინზე ზემოთ მდებარე ტრეკი (`V1`) კადრის ტილოზე ყველაზე ზემოდან იხატება.
- **ტრეკის მართვის ელემენტები**:
  - დააწკაპუნეთ `V1` / `V2` ნიშნულებს აქტიური სახატავი ფენის სწრაფად შესაცვლელად.
  - ფენის ხილვადობის (თვალი) და ჩაკეტვის (ბოქლომი) გადართვა.
  - ფენის გამჭვირვალობის რეგულირება (`0%..=100%`).
  - ფენის აწევა/დაწევა იერარქიაში, დუბლირება და ქვედა ფენასთან შერწყმა (Merge Down).
  - ფენის უსაფრთხო წაშლა დადასტურების დიალოგით.
- **კადრების კლიპები**:
  - შეკავების მამრავლი (Hold): კადრის ხანგრძლივობის მინიჭება (მაგ. `2×`, `3×` შეკავება პაუზებისთვის ან დარტყმის ფაზებისთვის).
  - დაკავშირებული კადრები: განმეორებადი ფაზების დაკავშირება, სადაც ერთის რედაქტირება მყისიერად ანახლებს ყველა დაკავშირებულ ასლს.
  - ტეგების ციკლი: ანიმაციის ორგანიზება დასახელებულ ტეგებად (`idle`, `walk`, `attack`) და კონკრეტული ტეგების განმეორებითი დაკვრა.
  - დაკვრის კონტროლი: წინ, უკან, პინგ-პონგი და ციკლი რეგულირებადი სიხშირით (`1..=120` FPS).

### 3. ანიმაციის ცოცხალი გადახედვა რეალურ დროში

მარჯვენა გადახედვის პანელი უკრავს თქვენს ანიმაციას რეალურ დროში, მთავარი ტილოს მასშტაბისა და პოზიციისგან სრულიად დამოუკიდებლად:
- **ტეგების ფილტრაცია**: დაკვრის იზოლირება კონკრეტულ ტეგებზე (`walk`, `jump`) ან მთლიანი ანიმაციური ჯაჭვის ჩვენება.
- **დაკვრის კონტროლი**: Play, Pause, წინა ნაბიჯი, შემდეგი ნაბიჯი, ციკლის გადართვა და დაკვრის სიჩქარე (`0.25x..=4.0x`).
- **ჩვენების რეჟიმები**: გადართვა მუქ ჭადრაკულ, ღია ჭადრაკულ, თეთრ, შავ ან მორგებულ ფონებს შორის.

### 4. კალკის გაუმჯობესებული ძრავა (Onion Skinning)

შექმენით გლუვი ანიმაცია სპეციალური კალკის სისტემით:
- **მორგებული ტონირება**: დამოუკიდებელი ფერები წინა კადრებისთვის (ნაგულისხმევი: წითელი) და მომდევნო კადრებისთვის (ნაგულისხმევი: ლურჯი).
- **გამჭვირვალობის მილევა**: საწყისი გამჭვირვალობისა და თითოეულ ნაბიჯზე მილევის მრუდის რეგულირება.
- **ციკლური შეკვრა**: პირველი და ბოლო კადრების ურთიერთგადაფარვა უნაკერო ციკლების შესაქმნელად.
- **სწრაფი შეხედვა (Quick-Peek)**: დაიჭირეთ <kbd>Space</kbd> მაუსის გადაადგილების გარეშე მეზობელი კადრების მყისიერად სანახავად.

### 5. რეფერენსის ჭკვიანი ესკიზისა და კონტურის ფენა

დააჩქარეთ მუშაობა ხელით დახატული ესკიზების ან რეფერენს-ფოტოების გამოყენებით:
- **ფორმატები**: PNG, JPEG და WebP რეფერენს-სურათების ჩატვირთვა.
- **შერევის რეჟიმები**: ქვეშ დადება (პიქსელური ფენების ქვეშ) ან ზემოდან დადება (პიქსელების ზემოთ).
- **ტრანსფორმაციის კონტროლი**: დამოუკიდებელი ზუმი, პოზიციის გადანაცვლება, როტაცია და გამჭვირვალობის სლაიდერი.
- **ჭკვიანი პიპეტი**: ფერის აღება ესკიზიდან აქტიური პროექტის პალიტრის უახლოეს ფერზე ავტომატური მიზიდვით.
- **1-დაწკაპუნებით გამოცხობა (Bake)**: მასშტაბირებული რეფერენსის მყისიერი გარდაქმნა სუფთა პიქსელებად აქტიურ კადრზე.

### 6. ზუსტი მონიშვნის ხელსაწყოები და «მორბენალი ჭიანჭველები»

- **ანიმირებული მორბენალი ჭიანჭველები**: აქტიური მონიშვნა გამოსახულია მაღალი კონტრასტის ორტონიანი მოძრავი წყვეტილი კონტურით.
- **მკვრივი ლასო შევსებით**: განსხვავებით მარტივი სხივის ალგორითმებისგან, რომლებიც ხვრელებს ტოვებენ გადაკვეთილ მარყუჟებზე, OniAnvil-ის ლასო ახდენს შეკრული 8-დაკავშირებული საზღვრის რასტერიზაციას და ავსებს გარე სივრცეს, რაც იძლევა 100%-ით მკვრივ მონიშვნას.
- **მონიშვნის ოპერაციები**: გაფართოება, შევიწროება, საზღვარი (წრის, კვადრატის, რომბის ფორმებით), გადაადგილება, ინვერსია, წაშლა, თავისუფალი მოტრიალება და ბუფერში კოპირება/ამოჭრა/ჩასმა.
- **კადრებს შორის კოპირება და ჩასმა**: მონიშნეთ არე ერთ კადრზე, დააჭირეთ <kbd>Ctrl/Cmd+C</kbd>-ს, გადადით სხვა კადრზე და დააჭირეთ <kbd>Ctrl/Cmd+V</kbd>-ს — პიქსელები ზუსტად იგივე კოორდინატებზე ჩაჯდება ნებისმიერი ენის კლავიატურაზე.

### 7. ცოცხალი ეფექტები, ფილტრები და RotSprite

ყველა ეფექტს აქვს ჩამრთველი **ცოცხალი გადახედვა (Live Preview)**, რომელიც ცვლილებებს ტილოზე აჩვენებს და საშუალებას გაძლევთ გააუქმოთ მოქმედება ისტორიის დანაგვიანების გარეშე:
- **ფერის შეცვლა (`Shift+R`)**:
  - ინტერაქტიული პიპეტი: აიღეთ ფერები პირდაპირ ტილოდან ან პალიტრის პანელიდან.
  - სწრაფი პალიტრის ზოლი: მარცხენა ღილაკით ირჩევა შესაცვლელი ფერი, მარჯვენათი — ახალი ფერი.
  - ტოლერანტობის სლაიდერი და ფერის ჯგუფური შეცვლა ანიმაციის ყველა კადრში ერთდროულად.
- **ფერების რეგულირება (`Ctrl/Cmd+U`)**: HSV ტონის (Hue), გაჯერების (Saturation), სიკაშკაშისა (Value) და კონტრასტის ცოცხალი კონტროლი.
- **ავტო-კონტურის გენერატორი**: პერსონაჟის მკვეთრი კონტურის შექმნა (გარე, შიდა, ცენტრალური) სწორი ან წაკვეთილი კუთხეებით.
- **3×3 მატრიცული ფილტრები**: დაბინდვა, სიმკვეთრე, კიდეების ამოცნობა და რელიეფი ალფა-არხის შენარჩუნებით.
- **თვითნებური მოტრიალება (`Ctrl/Cmd+R`)**: მონიშნული არის ან კადრის მობრუნება ნებისმიერი კუთხით კლასიკური **RotSprite** ან Nearest Neighbor ალგორითმით.
- **პალიტრაზე მორგება**: ტილოს ფერების გარდაქმნა აქტიურ პალიტრაში Bayer 2x2, 4x4, 8x8 ან Blue Noise დიზერინგით.

### 8. პალიტრების მართვა, ჩანაცვლება და პერსონაჟის სკინები

- **ჩაშენებული პალიტრები**: 20-ზე მეტი ავთენტური რეტრო პალიტრა, მათ შორის Game Boy, PICO-8, Commodore 64, NES, Endesga 32, Solarized და Sweetie 16.
- **იმპორტი და ექსპორტი**: GIMP Palette (`.gpl`), PAL (`.pal`), Hex (`.hex`) და სურათის ზოლების (`.png`) მხარდაჭერა.
- **პალიტრის ჩანაცვლება (სკინები)**: პერსონაჟისთვის რამდენიმე ფერადი ვარიანტის შექმნა (მაგ. ძირითადი, ოქროს ჯავშანი, ჩრდილი, ყინული). სკინის შეცვლა მომენტალურად ცვლის ფერებს მთელ ატლასში.
- **გრადიენტის რამპის გენერატორი**: ორ ფერს შორის გლუვი გადასვლის ავტომატური აგება ნაბიჯების მითითებული რაოდენობით.

### 9. სპრაიტ-ფურცლის დამჭრელი, 9-Grid ინტერფეისი და ექსპორტი თამაშის ძრავებისთვის

- **დამჭრელი (Sheet Slicer)**: ავტოკორელაციური ალგორითმი ავტომატურად ჭრის ნედლ სპრაიტ-ფურცლებს თანაბარ ან მჭიდროდ შემოფარგლულ ანიმაციურ კადრებად.
- **9-Grid (9-Slice) მასშტაბირება**: ინტერფეისის ღილაკებისა და პანელების კიდეების ზომების დაყენება კუთხეების დაუმახინჯებლად მასშტაბირებისთვის.
- **ექსტრუდირებული PNG ექსპორტი**: განაპირა პიქსელების დუბლირება გამჭვირვალე კიდეებში, რაც აქრობს ფილტრაციის არტეფაქტებსა და ნაკერებს OpenGL, DirectX, Vulkan და 2D ძრავებში (როგორიცაა Godot).
- **ანიმირებული GIF ექსპორტი**: ოპტიმიზებული GIF გენერატორი ციკლების რაოდენობის, კადრის დაყოვნებისა და გამჭვირვალობის მხარდაჭერით.
- **სტანდარტული Sprite Sheet JSON**: კადრების კოორდინატების, ტეგების, ხანგრძლივობისა და ღერძის წერტილების ექსპორტი თანამედროვე 2D ძრავების სტანდარტულ JSON ფორმატში.

- **Windows**: ჩამოტვირთეთ `OniAnvil-windows-x86_64.zip`, განარქივეთ და ორჯერ დააწკაპუნეთ `OniAnvil.exe`-ზე.
- **Linux**: ჩამოტვირთეთ `OniAnvil-linux-x86_64.tar.gz` (პორტატული) ან დააინსტალირეთ `onianvil_*_amd64.deb` პაკეტი Debian/Ubuntu-სთვის:
  ```bash
  sudo dpkg -i onianvil_*_amd64.deb
  ```
- **macOS**: ჩამოტვირთეთ `OniAnvil-macos-universal.zip`, განარქივეთ და გადაიტანეთ `OniAnvil.app` პროგრამების საქაღალდეში. უნივერსალური ფაილი მუშაობს როგორც Apple Silicon-ზე (M1/M2/M3/M4), ასევე Intel Mac-ზე.
- **Web**: გაუშვით პირდაპირ ბრაუზერში ინსტალაციის გარეშე: **[WebAssembly აპლიკაციის გახსნა](https://rbm13s.github.io/OniAnvil/app/?lang=ka)**.
  > [!WARNING]
  > ვებ-ვერსიას (WebAssembly) აქვს **ექსპერიმენტული (Experimental)** სტატუსი. ბრაუზერის იზოლაციის წესების, WebGL/WebGPU დრაივერებისა და ბუფერის შეზღუდვების გამო შესაძლებელია შეგხვდეთ მცირე გრაფიკული ხარვეზები ან დაბალი წარმადობა დესკტოპ ვერსიასთან შედარებით. კომფორტული და სრულფასოვანი მუშაობისთვის მკაცრად რეკომენდებულია ნატიური დესკტოპ ვერსიები.

### აგება საწყისი კოდიდან

#### წინაპირობები
- **Rust Toolchain**: დააინსტალირეთ Rust (რეკომენდებულია ვერსია 1.80+) [rustup.rs](https://rustup.rs/)-ის მეშვეობით:
  ```bash
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  ```
- **Linux-ის აგების დამოკიდებულებები** (Debian/Ubuntu):
  ```bash
  sudo apt-get update
  sudo apt-get install -y build-essential pkg-config libxcb-render0-dev libxcb-shape0-dev \
    libxcb-xfixes0-dev libxkbcommon-dev libxkbcommon-x11-dev libssl-dev libgtk-3-dev libgl1-mesa-dev
  ```

#### 1. ნატიური ვერსიის დაკომპილირება და გაშვება
```bash
# რეპოზიტორიის კლონირება
git clone https://github.com/rbm13s/OniAnvil.git
cd OniAnvil

# ტესტების გაშვება
cargo test

# ოპტიმიზებული რელიზის აგება და გაშვება
cargo run --release
```

#### 2. WebAssembly ვერსიის დაკომპილირება (Trunk-ით)
```bash
# wasm32 პლატფორმის და Trunk ამგების დამატება
rustup target add wasm32-unknown-unknown
cargo install --locked trunk

# ლოკალური dev-სერვერის გაშვება ავტო-განახლებით
trunk serve

# მზა რელიზის ფაილების აგება docs/app/ საქაღალდეში
./build_wasm.sh        # Linux / macOS-ზე
./build_wasm.ps1       # Windows PowerShell-ზე
```

## ფაილის ფორმატი და კომპანიონი არქიტექტურა

OniAnvil არ იყენებს ჩაკეტილ პროპრიეტარულ ბინარულ ფორმატებს. ყოველი პროექტი შედგება ორი სუფთა, ვერსიონირებადი ფაილისგან:

```
my_character/
├── my_character.png            # სტანდარტული PNG სპრაიტ-ფურცელი (იხსნება ნებისმიერ ძრავში ან დამთვალიერებელში)
└── my_character.onianvil.json   # კომპანიონი მეტამონაცემების ფაილი
```

`.onianvil.json` მეტამონაცემების ფაილი ინახავს:
- ტილოს ბადის კონფიგურაციას: კადრის ზომებს, სვეტების რაოდენობას, კადრების ჯამურ რიცხვს.
- ფენების იერარქიას: ტრეკების სახელებს, გამჭვირვალობას, ხილვადობისა და ჩაკეტვის ალმებს.
- ანიმაციის ტეგებს: სახელს, საწყისი/საბოლოო კადრების ინდექსებს, დაკვრის მიმართულებას, ხანგრძლივობას.
- პალიტრის განმარტებებს: აქტიურ ფერებს, დასახელებულ სკინებს, აქტიური სკინის ინდექსს.
- ესკიზის ფენის მდგომარეობას: სურათის მისამართს, მასშტაბს, გადანაცვლებას, კუთხეს, გამჭვირვალობას.
- ღერძის წერტილებს: სპრაიტის ცენტრს (Origin), იარაღის წერტილებსა და შეჯახების ცენტრებს.
